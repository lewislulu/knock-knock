knock-knock v1.0.0

English
Requires macOS 14 or later and Apple Silicon (M1 or later).
Drag knock-knock into Applications. Open it, then click Connect Calendar.
Use the calendar-and-clock menu bar icon to reopen the app.
This build is ad-hoc signed and is not Apple-notarized. If macOS blocks it,
verify the download source, then use System Settings > Privacy & Security >
Open Anyway if available. Managed Macs may restrict this option.
Keep the app running for reminders. Preview notice works without Calendar access.

简体中文
需要 macOS 14 或更新版本，以及 Apple Silicon（M1 或更新芯片）。
将 knock-knock 拖入「应用程序」，启动后点击「连接日历」。
点击菜单栏中的日历时钟图标可以重新打开应用。
此版本使用 ad-hoc 本地签名，尚未经过 Apple 公证。如果 macOS 阻止启动，
确认下载来源后，可前往「系统设置 > 隐私与安全性 > 仍要打开」（若可用）。
受管理的 Mac 可能限制此操作。提醒需要应用保持运行；预览无需日历授权。
